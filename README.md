# The Honeycomb Code

An interactive website about hexagon geometry: a Notice / Explain / Create project.

**Live site:** https://kursanovbael.github.io/hexagon-geometry-project/

## Sections
- **Notice:** why bees build hexagons, plus hexagons in basalt columns, dragonfly eyes and plant cells.
- **Explain:** the mathematics of why the hexagon uses the least wall material for the most space.
- **Create:** my own work inspired by honeycomb geometry.

## Built with
- HTML and CSS (responsive, dark theme with gradients and animations)
- [Three.js](https://threejs.org/) for the 3D rotating hexagon

## Adding images
Put photos in the `images/` folder using these names:
`honeycomb.jpg`, `basalt.jpg`, `dragonfly.jpg`, `plant-cells.jpg`, `my-creation.jpg`
