# The Honeycomb Code

Why does nature keep building hexagons? An interactive Notice / Explain / Create website about
hexagonal packing: why it is the most efficient shape, and how it appears at every scale in nature.

**Live site:** https://kursanovbael.github.io/hexagon-geometry-project/

## Sections
- **Quiz:** a one-question hook (which cell shape should a bee build?).
- **Notice:** honeycomb, then hexagons at seven scales, from dragonfly eye facets (~0.03 mm) to Saturn's polar storm (~29,000 km).
- **Explain:** which shapes can tile, an interactive wax-o-meter, the perimeter math, and the Honeycomb Conjecture.
- **Strength:** a live simulation of random cells relaxing into hexagons, plus 120° junctions and shared walls.
- **Create:** a build-your-own-honeycomb toy, my own creation, and a reflection.
- **Journey:** how my questions developed.

## Built with
- HTML, CSS and JavaScript (canvas animations)
- [d3-delaunay](https://github.com/d3/d3-delaunay) for the Voronoi simulation
